# Analizador de Frecuencias de Palabras

Script en Python para contar frecuencias de palabras en texto, manejar errores de lectura, generar gráficos con `matplotlib` y ejecutar pruebas unitarias con `pytest`.

## Dependencias
* Python 3.x
* `matplotlib`
* `pytest`

## Ejecución
* Ejecutar el script: `python analizador.py`
* Ejecutar las pruebas: `pytest test_analizador.py`
